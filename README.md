# my-project

一个 Python 脚本项目的起始骨架。

## 运行

```bash
python main.py
python main.py -n Chenstackhaiyan
```

需要 Python 3.8 及以上，目前没有第三方依赖。

## 结构

```
main.py           入口脚本
requirements.txt  第三方依赖清单
.gitignore        忽略规则
```

## 依赖安装

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
```
